    observe(obs, noise_node) classmethod ¶

    Interpret an existing observation as unknown true value plus noise.

    The returned value's posterior treats obs as a realization of theta + noise, where theta is a latent true value with a flat prior and noise is described by noise_node.

    noisy_min(*values) ¶

    Minimum of noisy values, as a new noisy value.

    Accepts several values or a single iterable, like the built-in min. The posterior of the result reflects the uncertainty about which input is smallest, not just the observed winner.

    The result is a NoisyInt if every input is an integer, otherwise a NoisyFloat. Raises ValueError if there are no inputs.

    noisy_max(*values) ¶

    Maximum of noisy values, as a new noisy value.

    Accepts several values or a single iterable, like the built-in max. The posterior of the result reflects the uncertainty about which input is largest, not just the observed winner.

    The result is a NoisyInt if every input is an integer, otherwise a NoisyFloat. Raises ValueError if there are no inputs.
